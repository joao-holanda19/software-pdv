# Pasta de Ativos (Assets) - PDV KNC Brasil

Esta pasta armazena mídias e arquivos do totem de autoatendimento.

### 🎥 Vídeo em Loop da Tela Inicial
- **Nome do arquivo**: `video-loop.mp4`
- **Caminho**: `assets/video-loop.mp4`
- **Recomendação**:
  - Resolução: 1080 x 1920 (Vertical / Portrait 9:16) ou 1080 x 1080
  - Formato: MP4 (H.264 / AAC)
  - Áudio: Pode conter áudio ou não (o totem roda em modo `muted` e `loop` contínuo automaticamente para não incomodar no salão de vendas).

### 🖼️ Imagens de Produtos (Opcional)
- Salve imagens de produtos aqui caso queira exibir fotos específicas no catálogo do LocalStorage (ex: `assets/coca.png`, `assets/nescau.png`).
